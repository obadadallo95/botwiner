# Verification of adversarial findings F01–F12

Research date: 2026-09-05

| ID | Classification | Verified result |
| --- | --- | --- |
| F01 | PARTIALLY CONFIRMED | `meta.fee` and ComputeBudget omitted direct Jito transfers. The claimed 10,000×/majority/range was unsupported: direct evidence found same-transaction tips in 101/2,395 transactions, with 82/1,201 event transactions and a 30,000,000-lamport maximum. Added explicit direct-transfer evidence and bundle caveat. |
| F02 | PARTIALLY CONFIRMED | Full blocks were accumulated and scale poorly; 139 validation blocks occupied 421MB raw. The claimed typical 15–50MB/block and inevitable first-call rejection did not match the sample: one measured block was ~2.5MB and all 139 succeeded. Default is now targeted transactions plus signature-only blocks, streamed in bounded batches; rebuild streams full blocks. |
| F03 | NOT CONFIRMED | Official `logsSubscribe` docs identify the notification as transaction logs but do not state the asserted N+1/N+2 evaluation-slot semantics. All 2,395 sample signatures were in exactly the observed context slot. Targeted `getTransaction` is now the default and supplies a definitive finalized slot, eliminating reliance on the assumption anyway. |
| F04 | CONFIRMED | One backfill-inclusive canonical file was unsafe as a future causal event pump, and normalized events intentionally exclude failed transactions. Outputs are now split into observed events, observed transactions including failures, and canonical post-hoc truth. |
| F05 | PARTIALLY CONFIRMED | Raw log counting is structurally weaker than the message list. However, the claim that ComputeBudget/System instructions do not emit invocation logs was contradicted by captured logs, and all 1,229 sample event indexes matched message correlation. Rebuild now correlates depth-1 programs to authoritative outer instructions and labels the source. |
| F06 | CONFIRMED | CU price without an explicit CU limit produced a null priority fee. Four sample transactions had this shape. The Agave type-dependent default calculation was implemented; all four results matched `meta.fee − message-signature base fees`. The audit's simple `200k × non-compute instructions` rule was incomplete because current builtins use 3k and ComputeBudget itself participates in default classification. |
| F07 | PARTIALLY CONFIRMED | The 5,000 cap already prevented an infinite walk and truncation was explicit. A dropped processed `until` boundary could still waste the bounded query and collect unrelated history. Both boundaries are now validated finalized at expected slots, results are slot-bounded, and cap behavior is tested. `minContextSlot` is not misused as a historical result filter. |
| F08 | CONFIRMED | When canonical fields tied or were absent, final lexicographic `eventId` ordering could order signatures arbitrarily. Missing transaction indexes now fall back to collector order. |
| F09 | PARTIALLY CONFIRMED | The metric mixes coarse block time, clock error, transit, and provider delay. The existing report already said it was not millisecond latency, so the audit overstated the absence of protection. An explicit `eligibleForExecutionModel: false` field now makes the prohibition machine-readable. |
| F10 | CONFIRMED | Reserves are post-trade and the amount ratio is average fill, not marginal/next executable price. Schema comments and a conservative helper were added. Standard adjacent events validated 633/633; Mayhem pre-state is deliberately unsupported. The audit's recommendation to invert a generic constant product was rejected as insufficient for Pump's exact fee/rounding/mode behavior. |
| F11 | CONFIRMED | Static rebuild coverage existed, but capture, retry, and pagination were untested. Mock-fetch tests now cover HTTP 429 retry, gap boundary validation/cap, targeted capture, and signature-only block requests. |
| F12 | PARTIALLY CONFIRMED | One SNTP sample cannot track drift, but it was already labeled single-sample evidence rather than an SLA and monotonic time was authoritative. Collection now repeats sampling every five minutes by default. |

Official evidence: [Solana logsSubscribe](https://solana.com/docs/rpc/websocket/logssubscribe), [Solana getBlock](https://solana.com/docs/rpc/http/getblock), [Solana getSignaturesForAddress](https://solana.com/docs/rpc/http/getsignaturesforaddress), [Solana fees](https://solana.com/docs/core/fees/fee-structure), [Agave runtime calculation](https://github.com/anza-xyz/agave/blob/master/compute-budget-instruction/src/compute_budget_instruction_details.rs), [Pump program docs](https://github.com/pump-fun/pump-public-docs/blob/main/docs/PUMP_PROGRAM_README.md), [Pump IDL](https://github.com/pump-fun/pump-public-docs/blob/main/idl/pump.json), and [Jito bundle/tip docs](https://docs.jito.wtf/lowlatencytxnsend/).
